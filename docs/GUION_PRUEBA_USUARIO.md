# Guion de Prueba de Usabilidad con Usuario Final — AgroDron (Tarea 4.2.2 / UI-04)

**Objetivo:** Validar que un agricultor o administrador de finca comprende en menos de 2 minutos el estado real de su cultivo, el déficit de plantas, las zonas críticas y cómo actuar en campo usando el nuevo Dashboard AgroDron y el Reporte PDF de 1 página.

**Duración estimada por participante:** 10 minutos.  
**Escenario de prueba:** Se muestra al agricultor la **Vista Agricultor** del vuelo del 22 de octubre de 2026 (Lote Piloto 1,0 ha — Vereda La Cabaña) y el Reporte PDF impreso/en pantalla.

---

## 1. Las 5 Preguntas Clave de Comprensión (Sin ayuda técnica)

| # | Pregunta al agricultor | Criterio de éxito (respuesta esperada) | ¿Entendió? (Sí / Parcial / No) | Tiempo (s) |
|---|---|---|---|---|
| **P1** | *Mirando la pantalla inicial, ¿cuántas plantas esperaba tener sembradas en la hectárea y cuántas estima el dron que hay vivas hoy?* | Identifica **2.500 esperadas** y la cifra estimada (~2.352) más el **déficit (~148 plantas / ~5,9 %)** sin confundirse con cifras técnicas de GSD o píxeles. | | |
| **P2** | *¿En qué zona o cuadrante del lote hacen falta más plantas y cuál tiene mayor prioridad de resiembra?* | Señala **Q3 (Sureste / SE)** o la zona marcada en alerta en la tabla/mapa de densidad y lee la recomendación en lenguaje llano. | | |
| **P3** | *En el mapa de cuadros de colores (celdas de 10 × 10 m), ¿qué significan los cuadros más oscuros o rojos frente a los verdes?* | Explica correctamente que el verde indica zonas bien pobladas (~23–25 plantas/cuadro) y el rojo/naranja muestra claros o huecos con menor densidad. | | |
| **P4** | *Si mañana envía a un trabajador a resembrar los huecos, ¿qué archivo descargaría de esta pantalla y para qué sirve?* | Identifica el botón **"Exportar Huecos (GPX / CSV)"** como la lista exacta de puntos GPS para llevar en el celular hasta cada sitio vacío. | | |
| **P5** | *Al ver la hoja del Reporte PDF de 1 página, ¿considera que la información es suficiente y clara para tomar decisiones sin un ingeniero al lado?* | Responde afirmativamente y logra resumir la recomendación principal de resiembra de la parte inferior del reporte. | | |

---

## 2. Evaluación Rápida de Usabilidad (Escala 1 = Totalmente en desacuerdo · 5 = Totalmente de acuerdo)

1. La información principal (plantas faltantes) se entiende apenas se abre la pantalla: `[ 1 ] [ 2 ] [ 3 ] [ 4 ] [ 5 ]`
2. Los textos, números y colores del mapa se leen cómodamente incluso bajo luz de campo: `[ 1 ] [ 2 ] [ 3 ] [ 4 ] [ 5 ]`
3. Cambiar entre la vista sencilla y la vista técnica es intuitivo y no estorba: `[ 1 ] [ 2 ] [ 3 ] [ 4 ] [ 5 ]`
4. El reporte PDF de 1 página sería útil para llevar un historial entre cosechas/vuelos: `[ 1 ] [ 2 ] [ 3 ] [ 4 ] [ 5 ]`
